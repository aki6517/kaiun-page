## 1. 参考素材の言語化（共通5観点）

### 実物鑑定書（継承すべき本家）
1. **色味**: 生成りに近い白地に、全要素がシャンパン〜アンティークゴールド1色。金文字には僅かなドロップシャドウがあり、箔押しの浮きを感じさせる
2. **光の質**: 拡散光。ページ全体が柔らかく発光しているような均質さ。強い陰影なし
3. **時間帯・季節感**: 夜明け（表紙の日の出線画が象徴）。季節を特定しない無時間性＝「儀式の時間」
4. **空間・距離**: 圧倒的な余白。1ページ1メッセージ、中央揃えの詩的な行送り。読者と1対1で向き合う近さなのに、神殿のような静けさ
5. **コアインサイト**: **これは販促物ではなく「あなたのためだけに整えられた一葉の証」**。余白と金の統一が「丁寧に扱われている」感覚を生み、¥2,000の値札より先に価値を伝える

### 装飾ボキャブラリー（実物から採取）
- 四隅のアールデコ扇型ライン（放射状の細線）
- 極細のゴールド二重線フレーム＋角の小さな渦飾り（表紙）
- 日の出／太陽の線画（表紙の紋章）
- ★★★★☆（金・大きめ・見出しと同行）
- ●見出し＋中黒（・）区切りのアイテム列挙
- 結び「〜 署名 〜」の様式

### 画像リサーチからの追加発見
- celestialジャンルは2路線: (A)漆黒×金のタロット系 (B)白×金の繊細エングレービング系。実物は(B)
- **架け橋レファレンス**: 白地×ダスティピンクの帯×金の星座線画のバースチャート（星の点＋細線・三日月中央・金の角飾りフレーム）——ルナのトンマナと紗々の世界観が同居できる証拠
- 日本の鑑定書テンプレ市場はパステル虹色・枠だらけの事務シート・Canva感が主流＝**実物の白×金は市場水準より上。ここで戦う**

## 2. デザインコンセプト

**「夜明けの祈祷書」** — 実物の白×金の品格を正統継承し、ルナの月とダスティローズを一滴だけ落とす。にぎやかさではなく静けさで、情報ではなく儀式で価値を伝える。

らしさの対比（〜ではなく〜）:
- 占いの販促物ではなく、**祈祷書の一頁**
- 情報シートではなく、**あなた宛の証**
- にぎやかな神秘ではなく、**静かな夜明け**
- 当てるための占いではなく、**自分軸に還す時間**

## 3. デザイントークン（実装の正本）

### 色
| 役割 | 値 | 用途 |
|---|---|---|
| 地（紙） | `#FDFBF7`（生成り白） | ページ・カード背景。純白は使わない |
| 金・主 | `#B08A4F`（アンティークゴールド） | 見出し・フレーム・線画・★。文字に使うのは見出しまで |
| 金・淡 | `#D9C08F` | 罫線・装飾の淡部・★の縁 |
| 墨（本文） | `#4A3F3B`（暖かい墨） | 本文テキスト。**可読性のため本文は金にしない**（WCAG AA確保） |
| 月の紅 | `#B7848C`（ダスティローズ） | 差し色。1画面1箇所まで（癒す言葉の帯・月の満ち欠け・ぼかしカードの錠前など） |
| 夜（外周） | `#2D2428` | メール外周・サイトの地とのつなぎのみ。カード内には持ち込まない |
| 金・濃（小文字用） | `#8A6A3B` | 小さい金文字（鑑定日・ラベル等の14px級）はこちら。`#B08A4F`は約3.2:1しかないため**24px以上または太字19px以上の見出し限定** |

### コントラスト計算（デザインゲート事前確認・#FDFBF7地）
- 本文 `#4A3F3B`: 約9.4:1 ✅AAA
- 見出し金 `#B08A4F`: 約3.2:1 → 大文字限定✅（小さい文字には使用禁止）
- 小文字金 `#8A6A3B`: 約4.9:1 ✅AA
- ローズ `#B7848C`: 約3.1:1 → 装飾・大文字限定（本文禁止）

### タイポグラフィ
- 見出し・儀式文字: **Shippori Mincho**（Google Fonts・セリフ）金色・字間広め（letter-spacing 0.12em）・中央揃え
- 本文: 同明朝の Regular・墨色・16px/行間2.0
- 組み: **見出し／癒す言葉／結び＝中央揃え**（実物の詩的様式を継承）、**運勢の本文段落＝左揃え・最大34em**（画面での可読性優先。全文中央・全文金は「紙の様式美」として捨てる）
- 数字・★は金。★の空きは `#D9C08F` の輪郭のみ

### 装飾（すべてインラインSVG・金1色の線画）
1. **コーナー扇**: 四隅のアールデコ放射扇（実物トレース基調）。カードの4隅に配置
2. **二重線フレーム**: 極細1px×2本＋角の渦。表紙ブロックと各セクションカードの枠
3. **日の出紋章**: 表紙ヒーローに1つ（実物の紋章を線画で再構成）
4. **月の満ち欠けディバイダー**: ●◐○◑●の5点＋細線。セクション間の区切り（ルナ要素・ローズ可）
5. **星の点**: 大小の＋と・を余白に極少数（架け橋レファレンスの星図から）

### レイアウト構造（結果ページ）
- 表紙ブロック: 二重線フレーム＋日の出紋章＋「鑑定書」（金明朝・大）＋「◯◯様」＋鑑定日
- 各セクション＝**1枚の「頁」カード**（生成り地・コーナー扇・上下たっぷりの余白・1カード1テーマ）。実物の「1ページ1メッセージ」をスクロールで再現
- 癒す言葉: ページ中央・「」付き・大きめ・下にローズの細帯
- ★評価: セクション見出し行に「金運 ★★★★☆」形式
- 有料ぼかしカード: 生成り地に金の枠＋月の錠前アイコン（ローズ）＋ぼかしダミー行。「準備中」の事務感を消し「まだ開かれていない頁」の演出
- 結び: 中央揃え「〜 紗々・マグダレナより愛を込めて 〜」＋小さな月線画

### メール（HTMLメールの制約に合わせた簡略版）
- 外周`#2D2428`・中身は生成りカード1枚。インラインCSSのみ・画像なし（装飾はunicode `─ ✦ ─` と罫線で代用）
- フォント指定は `'Shippori Mincho', 'Hiragino Mincho ProN', serif`（非対応クライアントは明朝系にフォールバック）
- メールは「表紙＋無料パート＋結果ページへの誘い」まで。**フル世界観は結果ページで見せる**（リンク誘導の動機にもなる）

## 4. NG（避けたい方向・必ず守る）

- パステル虹色・紫グラデ宇宙・ネオン発光（市場のCanvaテンプレ感）
- 枠と表を並べた事務シート型レイアウト（「記入欄」に見える）
- かわいい系イラスト・人物キャラ・絵文字（本文内。メール件名の🌙のみ可）
- 黒・紺の重い背景（タロット系(A)路線は不採用。ルナと不調和＆実物と別世界）
- 本文の長文を金文字にする（画面では可読性が死ぬ。金は儀式の枠と見出しだけ）
- ドロップシャドウの多用（実物の箔感の再現は見出しの1pxシャドウまで）
- 「準備中」「ロック中」等のシステム用語をユーザー向け表示に出す

## 5. 採用と切り捨ての整理

| 実物・参考から | 採る | 捨てる（理由） |
|---|---|---|
| 白×金の統一世界 | ✅ 全面採用 | — |
| 四隅の扇・二重線フレーム・日の出紋章 | ✅ SVGで再構成 | — |
| 1ページ1メッセージの余白 | ✅ 頁カード化 | — |
| 全文中央揃え・全文金 | 見出し/癒す言葉/結びのみ | 長文の中央×金は画面で読めない |
| ダスティローズ星図（架け橋） | 差し色・月満ち欠け・星点 | 全面ピンク化（紗々の品格が薄まる） |
| タロット系の黒×金 | ❌ | ルナ・実物と不調和 |
